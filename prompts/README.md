# AI prompts

Ready-to-import AI prompt files for Definer.

| Prompt | What it does |
| --- | --- |
| [Collocations](definer-ai-prompt-collocations.json) | Explore natural word combinations and their usage. |
| [Conjugation](definer-ai-prompt-conjugation.json) | Explain a selected verb form and compare useful forms. |
| [Mnemonic](definer-ai-prompt-mnemonic.json) | Create an invented memory aid for an expression. |

Add a downloaded JSON file through **AI → Settings → Prompts → New prompt → Import File**. Each prompt selects the **Lumetrium** provider and **Fast** model, using your available AI & Translation allowance.

The editable [Liquid templates](../src/prompts/README.md) are included separately. See the [AI prompts guide](https://lumetrium.com/definer/wiki/sources/ai/prompts/) for using and sharing prompts.
