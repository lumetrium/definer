# Customizations

Editable files for the sources and prompts in this catalog.

| Folder | Contents |
| --- | --- |
| [scripts](scripts/README.md) | JavaScript programs for Definer Script sources. |
| [prompts](prompts/README.md) | Liquid templates for Definer AI prompts. |
| [recipes](recipes/README.md) | The Recipe included with Lookup Notes. |

To try a customization, use its ready-to-import file from [sources](../sources/README.md) or [prompts](../prompts/README.md).

After editing a program or template, run `npm run build` from the repository root to regenerate the matching import files. The [catalog tools](../scripts/README.md) check that they stay in sync.
