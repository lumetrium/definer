# Recipes

[lookup-note.json](lookup-note.json) defines the **Save lookup note** Recipe included in the [Lookup Notes source](../../sources/definer-source-lookup-notes.json).

The Recipe creates a Note in a Collection using the current query and the note entered in the lookup result. It also carries the page URL and the `lookup-note` tag.

Import the complete Lookup Notes source to try the Script and Recipe together. This JSON is the editable Recipe definition used when rebuilding that source bundle with `npm run build`.
