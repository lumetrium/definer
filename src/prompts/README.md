# Prompt templates

Editable Liquid templates used by the [AI prompt import files](../../prompts/README.md).

| Template | Purpose |
| --- | --- |
| [collocations.liquid](collocations.liquid) | Natural word combinations, examples and usage. |
| [conjugation.liquid](conjugation.liquid) | A selected verb form and useful related forms. |
| [mnemonic.liquid](mnemonic.liquid) | An explicitly invented memory aid. |

Edit the template, then run `npm run build` from the repository root to update its JSON import file. The generated files select Lumetrium AI and Fast.

See the [AI prompts guide](https://lumetrium.com/definer/wiki/sources/ai/prompts/) for prompt editing and sharing in Definer.
